# Content Inventory

This project ships with a deterministic launch seed generated by `scripts/seed.mjs`.

Run:

```bash
pnpm db:push
pnpm db:seed
```

To reset and reseed launch content intentionally:

```bash
RESET_LAUNCH_CONTENT=true pnpm db:seed
```

This seed creates a broad launch content base, but a paid exam-prep product should still run human QA before heavy traffic. Remove weak items, calibrate difficulty, and improve explanations based on real user performance data.
